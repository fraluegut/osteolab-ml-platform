Taxón

Etapa 3 de la cascada: afinar dentro del grupo

Cuando la etapa 2 decide el grupo osteológico, una tercera etapa opcional afina más dentro de ese grupo — hoy, taxón (humano / carnívoro / ungulado / roedor) solo está entrenado para el grupo cráneo. El resto de grupos todavía no tienen experto de etapa 3 (se marca "no disponible" en Probarlo).

Cráneo

Examen honesto contra 52 fotos reales reservadas, nunca vistas en entrenamiento (scripts/eval_taxon_cranio_held_out.py). Accuracy global 0.692.

otro_primate quitado del taxón a petición del usuario (no viene al caso de uso) — eran 6 especies solo sintéticas, nunca tuvieron fotos reales con las que validar la clase. Accuracy global tras quitarla: 0.692 (mejor de 3 semillas probadas: 0.635 / 0.577 / 0.692 — con las 4 clases restantes hay bastante varianza entre corridas, n=52 es poco). Comparado con el run anterior que sí incluía otro_primate (0.769 global), el número baja un poco — esperable, quitar una clase no mejora las demás automáticamente, y aquí no se buscaba esa métrica sino simplificar el taxón al caso de uso real. Sigue sin haber fotos reales de gato doméstico en el repo — ver base_datos_osea/HISTORIAL.md, pendiente 103.
